# APP DEMO IDEA

I want to create a beautiful quote generator using this API: https://dummyjson.com/quotes/random

## Why
A small demo app for a workshop with a mixed technical audience.

## What I know
- Each request to the endpoint (GET, no authentication) returns one random quote.
- Contract:
  {"id":88,"quote":"That'S The Real Trouble With The World, Too Many People Grow Up","author":"Walt Disney"}
- The quote text comes in Title Case from the API.
